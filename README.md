# BudgetApp

BudgetApp is a household budgeting application for managing accounts, importing transactions, reviewing expenses, and creating personal and shared budgets.

## Tech Stack

- ASP.NET Core
- .NET 10
- React
- TypeScript
- Vite
- SQL Server

## Planned Scope

- User authentication
- Household management
- Account management
- CSV transaction imports
- Transaction review and categorization
- Monthly budget management
- Personal and household budget views
- Categorization rules
- AI-assisted categorization and spending insights
